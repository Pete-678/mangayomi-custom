## MANGA MILLION 使用方式

1. 更新儲存庫清單，啟用中文語言篩選，安裝「MANGA MILLION（繁體中文・測試版）」。
2. 先搜尋作品，或從熱門列表選擇作品。
3. 測試案例：章魚噼的原罪，第 001 話。
4. 開啟章節時會先下載並還原整章圖片，再交給 App 原生閱讀器，因此首次載入可能較慢，長篇章節會占用較多記憶體。

本來源要求 App 0.6.35 以上；介面是以目前 Mangayomi 公開主分支的 JavaScript HTTP 及 data URI 圖片處理程式為依據，尚未確認每個發行版本均可使用。

## 語言及圖片處理

- 網站介面 service_language 使用 zh-CN；漫畫翻譯固定 translated_language=zh-TW。
- 搜尋結果會再次檢查可用翻譯語言；章節只列出 FREE、SIMUL 群組。
- 閱讀時再次檢查章節實際語言及作品 ID；不符合就停止，不回退到其他語言。
- 使用網站公開網頁的匿名裝置註冊流程；不要求帳號、Cookie 或使用者 Token。
- 匿名裝置憑證及每章圖片參數只在 App 執行時取得，保存在執行記憶體，未內嵌於程式或公開清單。
- 依網站回應還原 AES-CBC 圖片，以 data URI 交給 Mangayomi。程式不下載或執行第三方 JavaScript。

## 0.1.2 修正

- 補上完整的瀏覽器識別與語言請求標頭，修正前版匿名裝置註冊的 HTTP 403。

- 清單指向此版本的固定 Git commit，避免下載到舊程式。

## 驗證狀態（2026-11-16）

**已完成真實網站端到端測試，手機 App 仍待實測。**

直接執行同一份 JavaScript 擴充程式，以 Python HTTP 適配器模擬 Mangayomi 的 Client 二進位回應介面：匿名註冊成功、列出 87 筆繁體作品，取得《章魚噼的原罪》可用繁體章節，並成功下載及還原第 001 話全部 48 頁，輸出為原生閱讀器可用的 WEBP data URI。測試未使用個人帳號、Cookie 或使用者憑證。

獨立 Python 解碼與 Pillow 驗證：第 1、24、48 頁均 HTTP 200，還原為 760×1080 WEBP。

本次終端整章測試約 179 秒；每個 HTTP 請求由獨立 Python 程序執行，不代表手機實際速度。由於必須先下載並處理整章，首次開啟仍可能明顯較慢。

離線回歸測試另驗證 AES-128/192/256 共 15 組獨立 crypto 標準測例、8 組 Base64 邊界、Protobuf、48 頁流程、缺省語言欄位、非繁體拒絕、作品 ID 檢查及缺譯章節排除。

可能限制：網站地區及存取限制、網站改版、App 的二進位 HTTP 或 data URI 支援差異、整章載入的時間與記憶體。回報問題請提供版本及錯誤畫面，不要傳送 Cookie、金鑰、密碼或 Token。
